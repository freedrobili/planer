# Планер

Минималистичный планировщик задач на Laravel: неделя по дням, задачи по часам, отметка выполненных.

## Запуск

```bash
composer install
cp .env.example .env && php artisan key:generate   # если .env ещё нет
php artisan migrate
php artisan serve
```

Откройте http://localhost:8000.

## Возможности

- Полоса недели с прогрессом по каждому дню, переход между неделями.
- Расписание дня по часам (06:00–23:00, расширяется, если есть более ранние или поздние задачи).
- Задачи без времени попадают в блок «В течение дня».
- Клик по пустому часу подставляет это время в форму добавления.
- Отметка выполнения и удаление без перезагрузки страницы, редактирование в диалоге.
- Цветные теги («Работа», «Личное», «Здоровье» и свои): у задачи может быть несколько тегов. Окно «+ Новый тег» позволяет создавать, переименовывать, перекрашивать и удалять теги (8 цветов).
- Фильтр по тегу над полосой недели: показывает только задачи с выбранным тегом, счётчики дней тоже считают только их. Фильтр сохраняется при переходе между днями и неделями, а новая задача сразу получает этот тег.
- Расписание пар (вкладка «Пары»): день недели, время, предмет, тип занятия, аудитория, преподаватель, чередование по чётным/нечётным неделям. Пары показываются в расписании дня вместе с задачами, занятые ими часы отмечены полосой слева. Необязательные даты семестра ограничивают показ пар и задают отсчёт чётности недель (без них используется номер недели в году).
- Линия текущего времени на сегодняшнем дне, светлая и тёмная темы, адаптивная вёрстка.

## Устройство

- `app/Http/Controllers/PlannerController.php` — страница недели и выбранного дня.
- `app/Http/Controllers/TaskController.php` — создание, изменение, отметка, удаление задач.
- `app/Http/Controllers/TagController.php`, `app/Models/Tag.php` — теги и список цветов.
- `app/Http/Controllers/LessonController.php`, `app/Models/Lesson.php` — пары и даты семестра.
- `app/Support/Timetable.php` — какие пары идут в конкретный день (чётность недели, границы семестра).
- `resources/views/layouts/app.blade.php` — общий каркас страниц; `planner.blade.php`, `schedule.blade.php`, `partials/` — разметка.
- `public/css/app.css`, `public/js/common.js`, `public/js/planner.js`, `public/js/schedule.js` — стили и скрипты, без сборки.
- База — SQLite (`database/database.sqlite`). Часовой пояс задаётся через `APP_TIMEZONE` (по умолчанию Europe/Moscow).
